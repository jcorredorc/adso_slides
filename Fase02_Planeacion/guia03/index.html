AA1 - Pensamiento Algorítmico

GA3-220501093-AA1

  • Duración: 14 horas
  • Objetivo: Desarrollar el pensamiento algorítmico mediante la lógica proposicional y representación de algoritmos.

Conceptos clave

  • Algoritmo: conjunto ordenado y finito de operaciones que resuelve un problema.
  • Pensamiento algorítmico: capacidad de descomponer problemas en pasos lógicos.
  • Lógica proposicional: proposiciones, conectores (AND, OR, NOT), tablas de verdad.
  • Análisis de problemas: identificar entradas, salidas y restricciones.
  • Representación: pseudocódigo y diagramas de flujo.

Lógica proposicional

Ejemplo de proposición compuesta:

(p ∧ q) → r

  • p: "Las palomas vuelan"
  • q: "Todas las aves tienen plumas"
  • r: "Las palomas son aves"

Tabla de verdad permite evaluar la validez del razonamiento.

Ejemplo práctico

Problema: Calcular el área de un triángulo rectángulo.

  • Entrada: base y altura (solicitadas al usuario).
  • Salida: área = (base × altura) / 2.

                        ALGORITMO areaTriangulo
                        VAR
                          REAL base, altura, area
                        INICIO
                          ESCRIBIR("Ingrese la base: ")
                          LEER(base)
                          ESCRIBIR("Ingrese la altura: ")
                          LEER(altura)
                          area ← base * altura / 2
                          ESCRIBIR("El área es: ", area)
                        FIN

  • EV02: Taller de resolución de problemas en pseudocódigo y diagramas de flujo (incluye investigación sobre diagramas de flujo).

AA2 - Estructuras de Control

GA3-220501093-AA2

  • Duración: 40 horas
  • Objetivo: Desarrollar soluciones algorítmicas utilizando estructuras secuenciales, condicionales y repetitivas.

Conceptos clave

  • Estructura secuencial: instrucciones ejecutadas una tras otra.
  • Estructura condicional: SI (condición) ENTONCES ... SINO ...
  • Estructuras repetitivas:
    • PARA (FOR): número fijo de iteraciones.
    • MIENTRAS (WHILE): se repite mientras se cumpla una condición.
  • Contadores y acumuladores: variables que incrementan o suman valores en cada iteración.
  • Funciones y procedimientos: modularidad para reutilizar código.

Estructura repetitiva FOR

Ejemplo: sumar los primeros N números naturales.


                        ALGORITMO sumarNaturales
                        VAR
                          ENTERO N, suma, i
                        INICIO
                          ESCRIBIR("Ingrese N: ")
                          LEER(N)
                          suma ← 0
                          PARA i DESDE 1 HASTA N
                            suma ← suma + i
                          FINPARA
                          ESCRIBIR("La suma es: ", suma)
                        FIN

Ejemplo práctico: Factorial

Problema: Calcular el factorial de un número dado (N!).

  • Entrada: N (entero positivo).
  • Salida: N! = 1 × 2 × ... × N.

                        ALGORITMO factorial
                        VAR
                          ENTERO N, fact, i
                        INICIO
                          ESCRIBIR("Ingrese N: ")
                          LEER(N)
                          fact ← 1
                          i ← 1
                          MIENTRAS i <= N
                            fact ← fact * i
                            i ← i + 1
                          FINMIENTRAS
                          ESCRIBIR("Factorial: ", fact)
                        FIN

AA3 - Arreglos y JavaScript

GA3-220501093-AA3

  • Duración: 42 horas
  • Objetivo: Solucionar problemas utilizando vectores, matrices y el lenguaje JavaScript.

Conceptos clave

  • Arreglos (arrays): colecciones de datos del mismo tipo.
    • Vectores: una dimensión (lista).
    • Matrices: dos o más dimensiones (tablas).
  • JavaScript: lenguaje interpretado, sintaxis flexible.
    • Tipos de datos: Number, String, Boolean, etc.
    • Operadores: aritméticos, relacionales, lógicos.
    • Estructuras de control: if...else, for, while.
    • Funciones propias y métodos de array (push, sort, filter).

Ejemplo: vector en JavaScript

Almacenar 5 números y mostrar los mayores a 100.


                        let numeros = [];
                        for (let i = 0; i < 5; i++) {
                            let valor = parseInt(prompt("Ingrese un número:"));
                            numeros.push(valor);
                        }
                        let mayores = numeros.filter(n => n > 100);
                        console.log("Mayores a 100:", mayores);

Ejemplo práctico: Matriz y registros

Matriz de 3×4 (productos y precios).


                        let datos = [
                            ["Manzana", "Pera", "Papaya", "Piña"],
                            ["Papa", "Tomate", "Yuca", "Ajo"],
                            ["Arroz", "Frijol", "Cebada", "Garbanzo"]
                        ];
                        // Acceder a un elemento:
                        console.log(datos[1][2]); // "Yuca"

Los registros se pueden modelar como objetos:


                        let persona = { nombre: "Juan", edad: 19, email: "juan@mail.com" };

AA1 - Principios y leyes físicas

GA3-220201501-AA1

  • Duración: 12 horas
  • Objetivo: Reconocer conceptos, principios y leyes fundamentales de la física aplicados al contexto productivo.

Conceptos clave

  • Leyes de Newton: inercia, fuerza-masa-aceleración, acción-reacción.
  • Principios de conservación: energía, momento lineal.
  • Medición y unidades: Sistema Internacional (SI).
  • Aplicaciones productivas: motores, sistemas hidráulicos, neumáticos, control de procesos.

Leyes de Newton en la industria

  • Primera ley: un objeto en reposo permanece en reposo a menos que actúe una fuerza. Aplicación: máquinas que requieren fuerzas para moverse.
  • Segunda ley: F = m·a. Cálculo de fuerzas necesarias en brazos robóticos.
  • Tercera ley: acción-reacción. Uso en propulsores y sistemas de sujeción.

Ejemplo práctico

Problema: Calcular la fuerza necesaria para acelerar un carro de 1000 kg a 2 m/s².

Solución: F = m × a = 1000 × 2 = 2000 N.

Este tipo de cálculos es común en diseño de vehículos y maquinaria.

AA2 - Cambios físicos de los cuerpos

GA3-220201501-AA2

  • Duración: 12 horas
  • Objetivo: Interpretar y explicar cambios físicos mediante medidas, gráficas y ecuaciones.

Conceptos clave

  • Tipos de medidas: longitud, masa, tiempo, temperatura, etc.
  • Gráficas: representación de datos (posición-tiempo, velocidad-tiempo).
  • Ecuaciones de movimiento: MRU, MRUV.
  • Cambios de fase: sólido, líquido, gas, y su relación con temperatura y presión.

Gráficas y ecuaciones

Ejemplo: Movimiento rectilíneo uniforme (MRU).

  • Ecuación: x = x₀ + v·t
  • Gráfica de posición vs tiempo es una línea recta con pendiente v.

Interpretación: permite predecir posiciones futuras y optimizar trayectorias en procesos productivos (transporte, logística).

Ejemplo práctico

Problema: Un carro se mueve a 20 m/s durante 5 s. ¿Qué distancia recorre?

Solución: x = v·t = 20 × 5 = 100 m.

Este cálculo es esencial en sistemas de control de velocidad y seguridad.

Evidencia

  • EV01: Video expositivo (3-7 min) sobre un experimento que demuestre una ley de Newton, con aplicación productiva.

AA3 - Manifestaciones de energía

GA3-220201501-AA3

  • Duración: 12 horas
  • Objetivo: Describir y explicar manifestaciones de energía en fenómenos físicos, considerando variables en contextos social y productivo.

Conceptos clave

  • Tipos de energía: cinética, potencial (gravitatoria, elástica), térmica, eléctrica, eólica, solar.
  • Conservación de la energía: la energía total de un sistema aislado permanece constante.
  • Transformaciones energéticas: de una forma a otra (ej. química → eléctrica → mecánica).
  • Parámetros físicos: masa, velocidad, altura, temperatura, etc.

Energía cinética y potencial

  • Energía cinética: Ec = ½ m v²
  • Energía potencial gravitatoria: Ep = m g h
  • Conservación: Ec₁ + Ep₁ = Ec₂ + Ep₂ (sin rozamiento).

Aplicaciones: diseño de montañas rusas, frenado regenerativo, almacenamiento de energía en presas.

Ejemplo práctico

Problema: Una masa de 2 kg cae desde 10 m de altura. Calcular su velocidad al llegar al suelo (despreciando rozamiento).

Solución: Ep = mgh = 2×9.8×10 = 196 J. Ec = ½ m v² = 196 → v = √(2×196/2) = √196 = 14 m/s.

Evidencia

  • EV01: Informe de laboratorio sobre conservación de la energía, incluyendo cálculos, gráficas, fotografías y conclusiones.

AA1 - Diálogos en contextos sociales

GA3-240202501-AA1

  • Duración: 48 horas
  • Objetivo: Dialogar sobre posibles soluciones a problemas en contextos sociales, usando expresiones de obligación y consejo.

Conceptos clave

  • Vocabulario: problemas sociales, medio ambiente, trabajo en equipo.
  • Gramática: have to, must, should para expresar obligación y recomendación.
  • Pronunciación y fluidez: entonación en preguntas y sugerencias.
  • Actos comunicativos: dar opiniones, hacer sugerencias, pedir y ofrecer ayuda.

Uso de have to / must / should

  • Have to: obligación externa (ej. "You have to wear a uniform.")
  • Must: obligación personal o regla (ej. "You must turn off your phone.")
  • Should: recomendación (ej. "You should recycle.")

Ejemplo práctico

Diálogo: Dos compañeros discuten cómo reducir el uso de plástico en la oficina.

  • A: "We should use reusable bottles."
  • B: "I agree. We must also separate waste."
  • A: "We have to inform the staff about recycling points."

Evidencias

  • EV01: Cuestionario (15 preguntas, 30 min) sobre el nivel 4 (A2.2).
  • EV02: Audio (2-5 min) en el que el aprendiz se presenta y habla sobre sus actitudes y obligaciones en el contexto laboral/académico, usando have to / must / should. Subir a Spreaker/Podbean y compartir URL.
  • EV03: Foro "Giving opinions about jobs" donde se responden preguntas sobre cómo ser ecológico en el trabajo y se comentan las participaciones de los compañeros.

AA2 - Reporte en contextos laborales

GA3-240202501-AA2

  • Duración: 48 horas
  • Objetivo: Reportar soluciones a problemas en contextos laborales, utilizando condicionales y expresando flexibilidad, adaptabilidad y liderazgo.

Conceptos clave

  • Condicionales: zero, first, second conditional para hablar de situaciones reales, posibles y poco probables.
  • Vocabulario de liderazgo y responsabilidad: flexibility, adaptability, decision-making, accountability.
  • Expresar planes y acciones: uso de will, going to, present continuous para futuro.

Condicionales en contexto laboral

  • Zero conditional: hechos generales (ej. "If you work hard, you succeed.")
  • First conditional: situaciones reales futuras (ej. "If we reduce costs, we will increase profits.")
  • Second conditional: situaciones hipotéticas (ej. "If I were the manager, I would implement flexible hours.")

Ejemplo práctico

Experiencia de adaptabilidad:

"Last year, our team had to work remotely. If we hadn't adapted quickly, we would have lost clients. We used new tools and held virtual meetings. This experience taught me the importance of flexibility."

Este tipo de narración utiliza condicionales y pasado para explicar soluciones.

Evidencias

  • EV01: Cuestionario (15 preguntas, 30 min) sobre el nivel 5 (B1.1).
  • EV02: Audio (2-5 min) donde el aprendiz habla sobre su trayectoria, planes y soluciones en contextos académicos y laborales, usando condicionales y vocabulario de liderazgo. Compartir URL.
  • EV03: Foro "Sharing life experiences" donde se comparte una experiencia de adaptabilidad en el trabajo y se responden preguntas sobre resultados y aprendizajes.
