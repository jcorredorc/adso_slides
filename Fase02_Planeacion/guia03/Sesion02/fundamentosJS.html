¿Qué es JavaScript?

  • JavaScript es un lenguaje de programación interpretado que se ejecuta principalmente en el navegador web.
  • Fue creado en 1995 por Brendan Eich en solo 10 días mientras trabajaba en Netscape.
  • A pesar de su nombre, no tiene relación directa con Java. Son lenguajes completamente diferentes.

¿Por qué JavaScript?

Ubicuidad

Presente en casi todas las páginas web modernas.

Versatilidad

Frontend, backend, móvil, escritorio, IoT...

Comunidad

Gran comunidad de desarrolladores y recursos.

* Es el lenguaje más utilizado según la encuesta anual de Stack Overflow desde 2013.

Evolución de JavaScript

A lo largo de los años, JavaScript ha evolucionado significativamente:

  • 1995: Nace como Mocha, luego LiveScript
  • 1997: Se establece el estándar ECMAScript
  • 2009: ES5 introduce mejoras importantes
  • 2015: ES6 / ES2015 revoluciona el lenguaje
  • Actualización anual desde entonces
Hoy aprenderemos la sintaxis moderna de JavaScript (ES6+)

Variables en JavaScript

Las variables son contenedores para almacenar datos que podemos usar y modificar en nuestro programa.

// Sintaxis básica
nombreVariable = valor;
En JavaScript moderno, usamos var, let o const para declarar variables antes de usarlas.

Declaración de variables

var

Tradicional (pre-ES6)

var edad = 18;
var nombre = "Ana";

Ámbito global o de función.

let

Moderna recomendada

let puntos = 75;
let activo = true;

Ámbito de bloque local.

const

Valores fijos

const PI = 3.1416;
const URL = "https://";

No se puede reasignar.

Ejemplos de Variables

// Usando let (valores mutables)
let contador = 0;
contador = contador + 1; // Incremento válido

// Usando const (valores inmutables)
const GRAVEDAD = 9.8;
// GRAVEDAD = 10; // Error: Asignación a variable constante

¿Cuándo usar cada tipo?

  • var: Evitar en código moderno por problemas de Scope o ámbito de función.
  • let: Para variables cuyo valor cambiará (contadores, acumuladores, loops).
  • const: Para variables de solo lectura, objetos o funciones fijas estructuradas.
Buenas prácticas: Usa const por defecto. Cambia a let solo si la lógica requiere reasignar el valor en memoria.

Tipos de datos básicos

Primitivos

  • String: "Texto"
  • Number: 42 o 3.14
  • Boolean: true / false
  • undefined: No asignado
  • null: Vacío intencional
  • Symbol / BigInt

Complejos / Referencia

  • Object: Estructuras clave-valor
  • Array: Listas ordenadas [1,2]
  • Function: Bloques ejecutables

Tipos de datos: Ejemplos

// Cadenas y números
let usuario = "María";
let edad = 28;
let frase = `${usuario} tiene ${edad} años`; // Interpolación

// Booleanos y nulos
let premium = true;
let descuento = null; 

// Objetos complejos
let curso = {
  titulo: "JavaScript",
  duracion: 40,
  activo: true
};

Tipado dinámico

JavaScript infiere el tipo dinámicamente y permite mutar el tipo de la variable en ejecución:

let valor = 100;      // Tipo inicial: Number
valor = "Cien";       // Cambia a: String
valor = false;        // Cambia a: Boolean
valor = { num: 100 }; // Cambia a: Object

* Brinda velocidad de desarrollo pero exige rigurosidad para mitigar bugs lógicos.

Operador typeof

Retorna una cadena indicando el tipo del operando actual:

console.log(typeof "Hola");     // "string"
console.log(typeof 4.5);        // "number"
console.log(typeof true);       // "boolean"
console.log(typeof [1, 2]);     // "object"
console.log(typeof null);       // "object" (Peculiaridad nativa)
console.log(typeof undefined);  // "undefined"

Operadores esenciales

Matemáticos

  • +, -, *, /
  • % Resto división
  • ** Potencia
  • ++, --

Asignación

  • = Directa
  • += Auto-suma
  • -= Auto-resta
  • *= Auto-mult.

Comparación

  • == Igual valor
  • === Estricto
  • != Distinto
  • !== Estricto
  • >, <, >=, <=

Ejemplos de Operadores

// Cálculos aritméticos comunes
let calculo = (10 * 2) + 5; // 25
let resto = 15 % 4;         // 3

// Operaciones de auto-asignación abreviadas
let total = 50;
total += 10; // total = 60
total *= 2;  // total = 120

// Incrementos unitarios
let pasos = 0;
pasos++; // pasos = 1

Comparación Estricta

let num = 10;
let str = "10";

console.log(num == str);   // true  (Compara solo valor)
console.log(num === str);  // false (Estricto: diferente tipo de dato)
console.log(num !== str);  // true  (Efectivamente son distintos en tipo)

let limite = 18;
console.log(limite >= 18); // true
Regla de oro: Emplear siempre triple igualdad (===) para evitar fallos por coerción implícita de tipos.

Operadores Lógicos

AND (&&)

Evalúa true solo si todos los operandos son ciertos.

let ok = true && false; // false

OR (||)

Evalúa true si al menos un operando es cierto.

let ok = true || false; // true

NOT (!)

Invierte el valor de cualquier booleano.

let invisible = !true; // false

Precedencia de Operadores

Jerarquía de resolución nativa (Mayor a Menor prioridad):

  1. Agrupación: ()
  2. Post-fijos: ++, --
  3. Lógicos Unarios: !
  4. Aritméticos Top: **, *, /, %
  5. Aritméticos Base: +, -
  6. Relacionales: <, >, <=, >=
  7. Igualdad: ==, ===, !=, !==
  8. Lógico AND: &&
  9. Lógico OR: ||
  10. Asignaciones: =, +=, -=

Estructuras de Control

Bifurcaciones

  • if / else if / else
  • switch (Mapeos discretos)
  • Operador Ternario

Bucles / Ciclos

  • for / for...of / for...in
  • while (Evaluación previa)
  • do...while (Post-evaluación)

Condicional if / else

let score = 85;
let rango;

if (score >= 90) {
  rango = "A";
} else if (score >= 70) {
  rango = "B";
} else if (score >= 50) {
  rango = "C";
} else {
  rango = "F";
}
console.log(rango); // Imprime: "B"

Estructura Switch

let codigoDia = 2;
let diaTexto = "";

switch (codigoDia) {
  case 1: diaTexto = "Lunes"; break;
  case 2: diaTexto = "Martes"; break;
  case 3: diaTexto = "Miércoles"; break;
  default: diaTexto = "Fin de semana u otro día";
}
console.log(diaTexto); // Imprime: "Martes"

Criterios: if vs switch

Usa IF para:

  • Rangos numéricos variables o dinámicos.
  • Condiciones complejas combinadas con operadores lógicos.

Usa SWITCH para:

  • Comparaciones directas frente a constantes.
  • Estructuras con múltiples opciones fijas uniformes.

Operador Ternario

Sintaxis compacta de una sola línea ideal para asignaciones rápidas:

// Estructura: condicion ? expresionTrue : expresionFalse;

let edad = 21;
let estado = (edad >= 18) ? "Acceso Permitido" : "Denegado";
console.log(estado); // "Acceso Permitido"

let temp = 32;
console.log(`Clima ${temp > 30 ? "Cálido" : "Templado"}`);

Bucle Clásico: for

Ejecuta un bloque un número conocido de veces:

// Contador básico del 1 al 3
for (let i = 1; i <= 3; i++) {
  console.log(i); // Imprime: 1, 2, 3
}

// Recorrido clásico indexado de arrays
let items = ["A", "B"];
for (let i = 0; i < items.length; i++) {
  console.log(items[i]);
}

Bucle while

Itera indefinidamente mientras la condición sea verdadera:

let pasos = 1;
while (pasos <= 3) {
  console.log(pasos);
  pasos++; // Condición de salida obligatoria
}
Peligro: Omitir el incremento generará un bucle infinito que colgará el navegador.

Bucle do...while

Garantiza de forma nativa que el cuerpo se procese **al menos una vez**:

let num = 10;
do {
  console.log("Ejecución garantizada"); 
  num++;
} while (num < 5); // Evalúa false, pero ya se ejecutó 1 vez.

Variantes: for...of y for...in

for...of

Accede a los valores directos de una colección.

let lista = ["X", "Y"];
for (let val of lista) {
  console.log(val); // "X", "Y"
}

for...in

Accede a las claves o propiedades de un objeto.

let user = { id: 1, rol: "admin" };
for (let key in user) {
  console.log(`${key}: ${user[key]}`);
}

Resumen de Estructuras Cíclicas

Bucle Uso sugerido
for Número exacto de pasos determinados o manipulación explícita de índices.
while La cantidad de ejecuciones depende de factores dinámicos externos.
do...while Casos donde se requiere operar antes de la validación lógica inicial.
for...of Lectura limpia y directa de colecciones tipo Array sin usar contadores.
for...in Inspección de atributos de configuración dentro de un Objeto JavaScript.

Caso Práctico 1: Promedios

let notas = [85, 90, 78, 92, 88];
let suma = 0;

for (let i = 0; i < notas.length; i++) {
  suma += notas[i];
}

let promedio = suma / notas.length;
let rango;

if (promedio >= 90) rango = "A";
else if (promedio >= 80) rango = "B";
else rango = "C";

console.log(`Promedio final: ${promedio} -> Equivale a: ${rango}`);

Caso Práctico 2: Números Primos

function esPrimo(numero) {
  if (numero < 2) return false;
  
  for (let i = 2; i <= Math.sqrt(numero); i++) {
    if (numero % i === 0) return false;
  }
  return true;
}

let test = [2, 3, 4, 5];
test.forEach(n => console.log(`${n} primo: ${esPrimo(n)}`));

Preguntas Metacognitivas

1. ¿Diferencia operativa entre let y const?
let habilita reasignación de primitivos en memoria. const bloquea la reasignación de la referencia (aunque permite mutar propiedades de arrays u objetos).

2. ¿Cuándo priorizar switch sobre estructuras condicionales anidadas?
Cuando se evalúan múltiples casos discretos e inmutables para una misma variable, optimizando legibilidad.

3. ¿Consecuencias de los bucles infinitos en producción?
Provocan desbordamiento de pila en el hilo de ejecución, congelando por completo la interfaz gráfica (UI).
